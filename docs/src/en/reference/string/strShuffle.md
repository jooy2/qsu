# strShuffle
Randomly shuffles the received string and returns it.

## Parameters

<ParamsTable :rows="[
	{ name: 'str', type: 'string', required: true }
]" />

## Returns

<ReturnType type="string" />

## Examples

::: lang js

```javascript
strShuffle('abcdefg'); // e.g. 'bgafced'
```

:::

::: lang dart

```dart
strShuffle('abcdefg'); // e.g. 'bgafced'
```

:::

::: lang python

```python
strShuffle('abcdefg')  # e.g. 'bgafced'
```
