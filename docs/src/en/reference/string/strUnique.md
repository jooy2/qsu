# strUnique <Lang dart js python />

Remove duplicate characters from a given string and output only one.

<ParamsTable :rows="[
	{ name: 'str', type: 'string', required: true }
]" />

## Returns

> string

## Examples

::: lang js

```javascript

```

```dart

```

:::

::: lang python
