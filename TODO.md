## Naming review

Every public function, parameter and option name in the three packages was read against its implementation in October 2026. The JavaScript signature and `lib/_types/global.ts` are the reference, and the Dart named parameters and Python keyword arguments were compared against them. The `is*` predicates, the `generate*` grouping, the `arr*`, `obj*`, `str*` and `num*` prefixes as such and camelCase in Python and Dart are deliberate and were not flagged. `isBotAgent`, `isMobile` and `generateLicense` were redesigned in the same round and are not listed.

A rename is a breaking change in every package, so it goes under "Breaking changes" in each changelog with the line a user has to change, as `getParsedInfoFromAddress` did in 1.21.0. Citations use three prefixes: `js:` is `packages/javascript/lib/`, `dart:` is `packages/dart/lib/src/` and `py:` is `packages/python/qsu/`. A name followed by "(+ `param`)" means the parameter is part of the same item.

### High: the name says something the code does not do

- [ ] `trim` (`string`, JavaScript, Dart, Python). Besides trimming the ends it collapses every inner run of whitespace into one space (`js:string/trim.ts:9`, `py:string/trim.py:11`), so `trim('a    b')` returns `'a b'`. `trim` and `strip` in all three standard libraries only touch the ends. Suggestion: `squish` (the Rails name) or `collapseWhitespace`.
- [ ] `strToAscii` (`string`, JavaScript, Dart, Python). Returns UTF-16 code units, not ASCII codes (`js:string/strToAscii.ts:4`, `py:string/strToAscii.py:5`): `strToAscii('é€')` is `[233, 8364]`. Suggestion: `strToCharCodes`.
- [ ] `removeSpecialChar` (+ `exceptionCharacters`) (`string`, JavaScript, Dart, Python). The kept set is only `a-zA-Z0-9`, Hangul, kana and CJK (`js:string/removeSpecialChar.ts:8`), so ordinary letters count as special: `removeSpecialChar('Müller café Привет')` returns `'Mllercaf'`. The singular `Char` also undersells a function that removes all of them. Suggestion: `removeSpecialChars`, treating every Unicode letter and digit as non-special; `exceptionCharacters` to `allowedCharacters`.
- [ ] `numUnique` (`math`, JavaScript, Dart, Python). Hands out a new, strictly increasing id (`js:math/numUnique.ts:4-14`), but its siblings `arrUnique` and `strUnique` remove duplicates, so it reads as "deduplicate numbers". Suggestion: `uniqueId` (lodash) or `numUniqueId`.
- [ ] `arrPick` (`array`, JavaScript, Dart, Python). Returns one random element (`js:array/arrPick.ts:6`), while `objPick(obj, keys)` keeps the listed keys. The same verb means "choose at random" in one place and "select by name" in the other. Suggestion: `arrSample` (lodash `sample`, Python `random.choice`), or `arrRandom` to pair with `strRandom`.
- [ ] `objMergeNewKey` (+ `obj2`) (`object`, JavaScript, Dart, Python). Despite the name and its doc ("add the newly added key data"), existing keys are overwritten as well (`js:object/objMergeNewKey.ts:42-43`): `objMergeNewKey({a: 1}, {a: 2, b: 3})` returns `{a: 2, b: 3}`. What sets it apart from `objMerge` is the `arrayAction` handling of arrays. Suggestion: Fold it into `objMerge` as an `arrayAction` option; if it stays separate, `objMergeWithArrays`. `obj2` to `source`.
- [ ] `deleteFile` (`file`, JavaScript, Dart, Python). Deletes a directory and everything in it (`js:node/file/deleteFile.ts:11-14` calls `rm` with `recursive` and `force`; `dart:file.dart:90`; `py:file/deleteFile.py:13` calls `rmtree`). A call named after a file can wipe a tree. Suggestion: `deletePath` (or `remove`, as in fs-extra).
- [ ] `deleteAllFileFromDirectory` (`file`, JavaScript, Dart, Python). Ungrammatical (`AllFile`), and it removes subdirectories too, because each entry goes through the recursive `deleteFile` (`js:node/file/deleteAllFileFromDirectory.ts:26`). Its doc says only the files go. Suggestion: `emptyDirectory` (fs-extra calls it `emptyDir`).
- [ ] `normalizeFile` (`file`, JavaScript, Dart, Python). Touches no file. It returns `filePath.normalize(form)`, a Unicode NFC/NFD normalization of the path string (`js:node/file/normalizeFile.ts:11`), and "normalizing a path" already means what `toValidFilePath` does. Suggestion: `normalizeFilePathUnicode`.
- [ ] `FileInfo.created` (`getFileInfo`) (`file`, JavaScript, Dart, Python). Filled from `ctime` (`js:node/file/getFileInfo.ts:26`), `st_ctime` (`py:file/getFileInfo.py:31`) and `FileStat.changed` (`dart:file.dart:159`). On Linux and macOS that is the last metadata change, not the creation time. Suggestion: `changed`. Dart's `FileStat` has no birth time, so a true `created` cannot be ported.
- [ ] `getUptime` (`os`, JavaScript, Dart, Python). Returns how long the current process has run (`js:node/os/getUptime.ts:5`, `process.uptime()`). "Uptime" means machine uptime everywhere else, the `uptime` command included, and here that value is `getSystemUptime`. Suggestion: `getProcessUptime`, which pairs with `getProcessMemoryUsage`.
- [ ] `decrypt.toBase64` (`crypto`, JavaScript, Dart, Python). In `decrypt` the flag says the input is Base64 (`js:node/crypto/decrypt.ts:14`). Nothing is converted to Base64, so the name reads backwards. On `encrypt` it is accurate. Suggestion: `encoding: 'hex' | 'base64'` on both functions; at minimum `fromBase64` on `decrypt`.
- [ ] `isUrl.withProtocol`, `isUrl.strict` (`verify`, JavaScript, Dart, Python). `withProtocol: true` makes the protocol optional by prepending `https://` (`js:verify/isUrl.ts:7`): `isUrl('example.com')` is `false` and `isUrl('example.com', true)` is `true`. The name reads as "require a protocol". `strict` only checks for a dot (`js:verify/isUrl.ts:2`). Suggestion: `allowMissingProtocol`; `strict` to `requireDot`.
- [ ] `isEqual` (`verify`, JavaScript, Dart, Python). Compares with loose `==` (`js:verify/isEqual.ts:10`; `py:verify/isEqual.py:1` re-creates the JavaScript coercion), so `isEqual(1, '1')` is `true` and `isEqual({a: 1}, {a: 1})` is `false`. Lodash's `isEqual`, the one most JavaScript users know, is the deep comparison qsu calls `isEqualDeep`. Suggestion: `isEqualLoose`, which gives the family `isEqualLoose`, `isEqualStrict`, `isEqualDeep`.
- [ ] `is2dArray` (`verify`, JavaScript, Dart, Python). True when any element is an array (`js:verify/is2dArray.ts:3`, the same in Dart and Python), so `[1, [2]]` and 3-D arrays pass. "2-D array" promises that every element is a row. Suggestion: `isNestedArray` (or `hasNestedArray`).
- [ ] `ParsedAddress.host` (`parseAddress`) (`net`, JavaScript, Dart, Python). Holds the hostname without the port (`js:net/parseAddress.ts:272-274`): `https://example.com:8080` gives `host: 'example.com'`. In the WHATWG `URL` and in Python's `urlsplit().netloc` the host includes the port. `protocol` is `'HTTPS'` rather than `'https:'`, and `user`/`pass` differ from `username`/`password`. Suggestion: Include `:port` in `host`, or drop it in favor of `hostname`; `user`/`pass` to `username`/`password`.

### Medium: grammatically wrong or inconsistent with its siblings

- [ ] `arrGroupByMaxCount` (+ `maxLengthPerGroup`) (`array`, JavaScript, Dart, Python). Splits an array into fixed-size chunks (`js:array/arrGroupByMaxCount.ts:7-10`). Nothing is grouped by a key, unlike its neighbor `arrGroupBy`, which returns an object keyed by the callback. Suggestion: `arrChunk(array, size)` (lodash `chunk`).
- [ ] `arrWithNumber` (`array`, JavaScript, Dart, Python). Builds a numeric range with an inclusive end (`js:array/arrWithNumber.ts:14`). "With number" does not say range. Suggestion: `arrRange`, with the inclusive end stated in its docs, since lodash and Python ranges exclude it.
- [ ] `arrTo1dArray`, `objTo1d` (`array, object`, JavaScript, Dart, Python). One operation, flattening, named two ways: with an `Array` suffix and without, both with the jargon `1d`. Suggestion: `arrFlatten`, `objFlatten`.
- [ ] `sortNumeric`, `sortByObjectKey.numerically` (`array`, JavaScript, Dart, Python). Both apply the natural order in `js:array/_naturalCompare.ts` (digit runs as numbers, then letters, accents and case), so `sortNumeric` also orders strings that hold no digits. `Intl.Collator`'s `numeric` option is a precedent for the word, but "natural sort" is the established name. Suggestion: `sortNatural`; `numerically` to `natural`.
- [ ] `safeJSONParse` (`format`, JavaScript, Dart, Python). Capitalizes the acronym where the rest of the API camel-cases it, and reverses the word order of its sibling `safeParseInt`. Suggestion: `safeParseJson`.
- [ ] `HTTPRequestOption`, `ParsedAddress.isIP`, `ParsedAddress.isIPv6` (`types, net`, JavaScript types; the fields in all three). Acronyms in capitals, while function names camel-case them: `isUrl`, `escapeHtml`, `getLocalIp`, `getCpu`, `getOsName`. Suggestion: `HttpRequestOptions`, `isIp`, `isIpv6`.
- [ ] `HTTPRequestOption`, `GetUptimeOption`, `opt` (`types, os`, JavaScript types; `opt` in JavaScript and Python). Singular `Option` where the other option types are plural (`RetryOptions`, `PadOptions`, `SlugOptions`, `DurationOptions`, `GetFontsOptions`). `getUptime` and `getSystemUptime` name the parameter `opt` instead of `options` (`js:node/os/getUptime.ts:4`). `LicenseOption` has the same problem but belongs to the `generateLicense` redesign. Suggestion: `HttpRequestOptions`, `UptimeOptions`; `opt` to `options`.
- [ ] `DurationOptions.withMilliSeconds` (`format`, JavaScript, Dart, Python). Splits "millisecond" into two words, while the unit itself is spelled `Millisecond` (`DurationUnitName` in `js:_types/global.ts`). Suggestion: `withMilliseconds`.
- [ ] `DurationOptions.useShortString` (`format`, JavaScript, Dart, Python). Says what `FileSizeOptions.unitDisplay: 'short' | 'long'` already says, under a vaguer name. Suggestion: `unitDisplay: 'short' | 'long'`, defaulting to `'long'`.
- [ ] `numPick` (`math`, JavaScript, Dart, Python). Returns a random integer in a range (`js:math/numPick.ts:9`). "Pick" means selecting keys in `objPick`, and the random string generator is `strRandom`. Suggestion: `numRandom` (lodash `random`, Python `random.randint`).
- [ ] `max`, `min`, `sum`, `round`, `len`, `sleep`, `contains`, `isEmpty` (`math, verify, misc`, Python, Dart). In Python, `from qsu import *` replaces builtins with different behavior: `sum([1, 2], 10)` is `3` instead of `13`, `round(2.5)` is `3` instead of `2`, and `len(12345)` is `5` instead of a `TypeError`. qsu's `sleep` takes milliseconds where `time.sleep` takes seconds. In Dart, `max` and `min` clash with `dart:math`, `sleep` with `dart:io`, and `contains` and `isEmpty` with `package:test`, which this repository's own tests already hide (`packages/dart/test/verify_test.dart:2`). Suggestion: `numMax`, `numMin`, `numSum`, `numRound` under the existing `num*` prefix; document the clashes for the rest.
- [ ] `getRamSize`, `getFreeRamSize`, `getUsedRamSize`, `getDiskSize`, `getFreeDiskSize` (`os`, JavaScript, Dart, Python). Return a formatted string such as `'16 GB'`, rounded up with no decimals (`js:node/os/getRamSize.ts:5`), while `getFileSize` returns a number of bytes. The same `*Size` noun has two return types. Suggestion: Return bytes like `getFileSize` and let callers use `fileSizeFormat`; otherwise a `*SizeText` suffix.
- [ ] `getProcessMemoryUsage` (`os`, JavaScript, Dart, Python). Returns a formatted size (`js:node/os/getProcessMemoryUsage.ts:5`), while `getRamUsage`, `getDiskUsage` and `getCpuUsage` return percentages. It also says "Memory" where its siblings say "Ram". Suggestion: `getProcessRamSize`.
- [ ] `getCpu` (`os`, JavaScript, Dart, Python). Returns only the model string of the first core (`js:node/os/getCpu.ts:4`). Next to `getCpuCount`, `getCpuSpeed` and `getCpuUsage` it reads as "all CPU information". Suggestion: `getCpuModel`.
- [ ] `getHostname` (`os`, JavaScript, Dart, Python). On macOS it returns the ComputerName from System Settings (`Sam's MacBook`), and on Windows the JavaScript and Python versions return `COMPUTERNAME` (`js:node/os/getHostname.ts:11,19`). A value with spaces and an apostrophe is not a hostname. Suggestion: `getComputerName` for this value, keeping `getHostname` for the network hostname.
- [ ] `isFileExists` (`file`, JavaScript, Dart, Python). Ungrammatical, and also true for directories (`js:node/file/isFileExists.ts:9`; the Dart doc at `dart:file.dart:442` says "file or directory"). Suggestion: `pathExists`, or `isExistingPath` to stay in the `is*` group.
- [ ] `createFileWithDummy` (`file`, JavaScript, Dart, Python). "With dummy" does not say what is made: a file of exactly `size` bytes (`js:node/file/createFileWithDummy.ts:20`). Suggestion: `createFileOfSize(filePath, size)`.
- [ ] `isValidFileName.unixType` (`file`, JavaScript, Dart, Python). Vague, and its default applies Windows rules, while every sibling takes `isWindows` with a POSIX default (`isFileHidden`, `getParentFilePath`, `joinFilePath`, `toValidFilePath`). Suggestion: `isWindows`, defaulting to `true` here to keep the behavior; or one `platform` option across the file helpers.
- [ ] `toValidFilePath` (`file`, JavaScript, Dart, Python). Normalizes the path, anchors a relative one at the root (`../../etc` becomes `/etc`) and strips the trailing separator (`js:node/file/toValidFilePath.ts:29-46`). "Valid" describes none of that. Suggestion: `normalizeFilePath`, once `normalizeFile` is renamed.
- [ ] `capitalizeEachWords` (+ `natural`) (`string`, JavaScript, Dart, Python). "Each" takes a singular noun. `natural` switches to title case: it lower-cases the text and skips a list of minor words (`js:string/capitalizeEachWords.ts:11-45`). Suggestion: `capitalizeEachWord`; `natural` to `titleCase`.
- [ ] `capitalizeEverySentence` (+ `splitChar`) (`string`, JavaScript, Dart, Python). "Every" here and "Each" in its sibling. `splitChar` is what `dateToYYYYMMDD`, `objTo1d`, `duration` and `getSlug` call `separator`. Suggestion: `capitalizeEachSentence`; `splitChar` to `separator`.
- [ ] `removeNewLine` (+ `replaceTo`) (`string`, JavaScript, Dart, Python). Also trims the result (`js:string/removeNewLine.ts:6`), removes every newline although the name is singular, and splits "newline" into two words. `replaceTo` is not idiomatic and differs from `replaceWith` in `replaceBetween`. Suggestion: `removeNewlines(str, replaceWith)`.
- [ ] `replaceBetween` (+ `startChar`, `endChar`) (`string`, JavaScript, Dart, Python). Replaces the delimiters too (`js:string/replaceBetween.ts:21`): `replaceBetween('a[b]c', '[', ']', 'X')` returns `'aXc'`, where "between" suggests `'a[X]c'`. The docs say so, but the name argues with them. `startChar` and `endChar` accept strings of any length. Suggestion: `replaceEnclosed`; `startChar`/`endChar` to `start`/`end`.
- [ ] `strBlindRandom` (+ `blindLength`, `blindStr`) (`string`, JavaScript, Dart, Python). "Blind" is not the English word for masking. `blindLength` is the number of characters masked and `blindStr` is the mask. Suggestion: `strMaskRandom(str, maskCount, maskChar)`.
- [ ] `getStrBytes` (`string`, JavaScript, Dart, Python). Returns a count of UTF-8 bytes rather than the bytes, and puts the `str` prefix in the middle of the name. Suggestion: `strByteLength` (after Node's `Buffer.byteLength`).
- [ ] `truncateExpect` (+ `expectLength`, `endStringChar`) (`string`, JavaScript, Dart, Python). Cuts at the end of the sentence that crosses `expectLength` (`js:string/truncateExpect.ts:66-69`), so the length is a minimum. "Expect" reads like a test assertion, and `endStringChar` takes a string or a list of strings. Suggestion: `truncateSentence(str, minLength, sentenceEnds)`.
- [ ] `objFindItemRecursiveByKey` (+ `childKey`) (`object`, JavaScript, Dart, Python). Matches a key and a value (`item[searchKey] === searchValue`, `js:object/objFindItemRecursiveByKey.ts:20`) and descends through `childKey`. "ByKey" and the word order hide both. Suggestion: `objFindInTree(obj, key, value, childrenKey)`.
- [ ] `objToPrettyStr` (`object`, JavaScript, Dart, Python). `Str` here, `String` in its sibling `objToQueryString`. The output is JSON (`js:object/objToPrettyStr.ts:4`). Suggestion: `objToPrettyJson`.
- [ ] `isObject` (`verify`, JavaScript, Dart, Python). True only for plain objects (`js:verify/isObject.ts:2`). Lodash's `isObject` is true for arrays and functions and calls this check `isPlainObject`. Python tests `type(data) is dict` and Dart `data is Map`. Suggestion: `isPlainObject`.

### Parameters that differ between the languages

Parameter names agree for nearly every function. The real differences are `arrMove` and the right operands of `isEqual` and `isEqualStrict` in Dart; the other items pass the same name differently, which a rename pass should settle at the same time.

- [ ] `arrMove`: JavaScript takes `from`, `to`, Dart `from`, `to` and Python `fromIndex`, `to`. `from` is a Python keyword. `fromIndex` and `toIndex` would work in all three.
- [ ] `isEqual`, `isEqualStrict`: JavaScript takes `leftOperand, ...rightOperand`, Dart `leftOperand, [right1, right2]` and Python `leftOperand, *rightOperand`. Dart takes at most two right operands unless they arrive as one list.
- [ ] `joinFilePath`: JavaScript takes `isWindows, ...paths`, Dart `paths, {isWindows}` and Python `isWindows, *paths`. Same names, different order and kind.
- [ ] `getDiskSize`, `getFreeDiskSize`, `getDiskUsage`: JavaScript takes `path` (positional), Dart `{path}` (named) and Python `path` (positional). Same name, different kind.
- [ ] `getUptime`, `getSystemUptime`: JavaScript takes `opt: {format, floor}`, Dart `{format, floor}` and Python `opt` dict or keyword arguments. Only JavaScript and Python have the container, and they call it `opt`.
- [ ] `fileSizeFormat`, `getSlug`: JavaScript takes options object, Dart named parameters and Python flat keyword arguments only. Python takes no options dict here, unlike the other Python functions with options (CLAUDE.md describes both forms).
- [ ] `createFileWithDummy`: JavaScript takes `size` (required), Dart `{int? size}` (optional, throws when missing) and Python `size` (required). Same name; Dart should make it a required positional.
- [ ] `arrGroupByMaxCount`: JavaScript takes `maxLengthPerGroup = 1`, Dart `maxLengthPerGroup` (required) and Python `maxLengthPerGroup = 1`. Same name, different default.
- [ ] `arrWithDefault`: JavaScript takes `length = 0`, Dart `length` (required) and Python `length = 0`. Same name, different default.
- [ ] `div`, `max`, `min`, `mul`, `sub`, `sum`, `logBox`, `split`, `urlJoin`, `objMerge`, `arrIntersection`, `arrDifference`: JavaScript takes rest parameter, Dart one `List` parameter and Python `*args`. Names agree. Only the shape differs, which Dart requires.

`getMacAddress` and `getTimezone` exist only in JavaScript, and `console` only in Dart.
