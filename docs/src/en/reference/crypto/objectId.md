# objectId
<NodeRequired en />

Returns a random string hash of the ObjectId format (primarily utilized by MongoDB).

## Parameters

No parameters required

## Returns

<ReturnType type="string" />

## Examples

::: lang js

```javascript
objectId(); // e.g. '651372605b49507aea707488'
```

:::

::: lang dart

```dart
objectId(); // e.g. '651372605b49507aea707488'
```

:::

::: lang python

```python
objectId()  # e.g. '651372605b49507aea707488'
```

:::
