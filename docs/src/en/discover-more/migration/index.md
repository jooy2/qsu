# Migration

Each guide takes one library. It maps that library's functions to qsu's, marks the pairs that look alike but behave differently, and lists what qsu has no answer for. None of them describes a drop-in replacement, so read the notes before deleting anything.

If you are still deciding whether qsu belongs in your project, start with [Comparison](../comparison).
