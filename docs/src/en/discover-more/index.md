# Discover more

Most projects already have a utility library. This section is for deciding whether qsu belongs next to yours, and for moving over if it does.

[Comparison](./comparison) puts qsu beside the best-known utility libraries of each language and sets out what each one covers, how its API is shaped and where it runs.

The migration guides take one library each. Every guide maps that library's functions to qsu's, marks the pairs that look alike but behave differently, and lists what qsu has no answer for. None of them describes a drop-in replacement, so read the notes before deleting anything.
